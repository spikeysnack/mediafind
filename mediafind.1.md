# NAME
mediafind \- a program to find audio and video files f a s t.

# SYNOPSIS
**mediafind** [*OPTIONS*] *search_term*

# DESCRIPTION
**mediafind** is a command-line tool to make, update, and search  \
local locate database files, specifically for audio and media stores.
(It could be used for any types of files.)

# OPTIONS
**-h, help**
: Show help message

**-d, dirs_only**
: Output dirs only with matching files

**-m, metadata**
: Show metadata (json format)

**-u, update** 
: Update databases**

**-a, audio_only**
: Search audio databases only

**-v, video_only**
: Search video databases only
